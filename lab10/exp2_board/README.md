# exp2_board — 五段流水线 CPU 上板工程

上板时把这 6 个文件加入工程，顶层设为 `cpu_top`：

| 文件 | 作用 |
| :--- | :--- |
| `cpu_top.v` | 顶层：复位、时钟选择、单步消抖、周期计数、存储器映射 I/O、数码管 |
| `rv32ip.v` | 流水线 CPU，与 `../exp1_cpu/rv32ip.v` 相同 |
| `prog_rom.v` | 4 × 256 字指令 ROM，同步读 |
| `board_dmem.v` | 4KB 数据存储器 |
| `prog.hex` | 指令 ROM 初始化文件，`make_rom.py` 生成 |
| `cpu_top.xdc` | Nexys A7-100T 引脚约束 |

## 与单周期版本的区别

程序、存储器映射和引脚约束与 lab09 完全相同，差别只在 CPU 和时钟：

- `rv32ip` 的一步是"一个完整周期"：上升沿读指令/读数据存储器/写回寄存器，
  下降沿更新 PC 和四个段寄存器。自动模式给连续 25MHz 时钟；单步模式用 BTNC
  产生一个 10ns 脉冲，所以**按一次 BTNC 只让流水线前进一个周期**，PC 和结果
  一个一个节拍地变化。
- 顶层多了一个 32 位周期计数器 `cyc_cnt`，`SW[12]=1` 时数码管改为显示
  已经执行了多少个 CPU 周期。同一个程序在流水线上通常比单周期多不少周期，
  这些周期就是跳转冲刷和 load-use 阻塞插入的气泡。
- `LED[15:0]` 显示 PC 低 16 位。停机循环 `j hang` 里流水线会顺序预取
  `hang+4`、`hang+8` 再被冲刷回来，所以 LED 会在这三个值之间快速跳动。
  单步模式下每按一次 `BTNC` 也会在这三个地址之间循环，这是 EX 阶段跳转冲刷
  的正常现象，不是没有停机；结果寄存器已经不再变化，判断停机以数码管结果为准。
  自动模式下 25MHz 太快，人眼看到的是三个地址的按位或：累加和
  `0x28|0x2C|0x30=0x3C`，斐波那契 `0x34|0x38|0x3C=0x3C`，闰年
  `0x44|0x48|0x4C=0x4C`，素数 `0x48|0x4C|0x50=0x5C`。单步模式每次只显示
  一个地址，看到的是准确值。

## 板上操作

- `SW[15:14]`：选择程序

| 值 | 程序 | 结果 |
| :---: | :--- | :--- |
| 00 | 累加和 $1+2+\cdots+n$ | $n(n+1)/2$ |
| 01 | 斐波那契 $F(n)$ | $F(0)=0$，$F(1)=1$ |
| 10 | 闰年判断 | 1 表示闰年，0 表示不是 |
| 11 | 素数判断 | 1 表示素数，0 表示不是 |

- `SW[13]`：1 为自动运行，默认 25MHz；0 为 BTNC 单步，每按一次走一个周期。
- `SW[12]`：0 显示程序结果，1 显示已执行的 CPU 周期数。自动模式下周期数变化很快，这个显示主要用于单步。
- `SW[11:0]`：参数 n，三位十六进制，范围 `0x000` 到 `0xFFF`。
- `CPU_RESETN` 是板上红色 CPU RESET 按钮，低有效。上电时另有约 2.6ms 的上电复位；
  改参数或换程序时先设好开关，再按一下 `CPU_RESETN`，复位期间开关被锁存；
  `BTNC` 只用于单步，不是复位。

上板流程：先设好程序、模式和 n，按一下红色 `CPU_RESETN` 锁存并复位；
`SW[13]=1` 时程序自动运行到停机，`SW[13]=0` 时用 `BTNC` 逐条执行；
结果显示在数码管上。按住复位时 PC 和显示保持 0，松开后自动模式会马上重跑。

## 频率配置

默认按 25MHz 构建：

| 目标 | `cpu_top.v` 的 `DIV_BITS` | XDC 的 `-edges` |
| :---: | :---: | :---: |
| 25MHz | 2 | `{1 3 9}` |
| 50MHz | 1 | `{1 3 5}` |

25MHz 用 100MHz 四分频，周期 40ns，高电平 10ns；50MHz 用二分频，周期
20ns，高电平 10ns。两个地方必须同时改，只改一处会让时序分析和板上波形
对不上。仿真时 `cpu_top_tb.v` 里的 `DIV_BITS` 也要跟着改。50MHz 是尝试
目标，先跑 implementation 看 WNS；如果 Setup Slack 为负，先看 ID/EX、
EX/MEM 段间路径，必要时回退 25MHz 或拆分 EX 段。

## 修改程序

汇编源码是 `prog_sum.S`、`prog_fib.S`、`prog_leap.S`、`prog_prime.S`，
由 `tools/rvasm.py` 汇编。改完后重新生成 `prog.hex`：

```bash
cd lab10/exp2_board
python3 make_rom.py
```

`rv32ip.v` 是 `../exp1_cpu/rv32ip.v` 的副本，改 CPU 后两边要同步：

```bash
cp ../exp1_cpu/rv32ip.v rv32ip.v
```

## 仿真

在 `exp2_board` 目录下运行，`prog.hex` 就在当前目录：

```bash
docker run --rm -v "$PWD":/work -w /work iverilog:12 \
  sh -c "iverilog -g2012 -o /tmp/t.out cpu_top.v rv32ip.v prog_rom.v board_dmem.v cpu_top_tb.v && vvp /tmp/t.out"
```

自检覆盖 4 个程序的 21 组参数，检查结果寄存器、停机循环、LED、数码管段码，
另外检查周期数显示模式和单步执行。
